Panduan & keselamatan
  1. Pilih tab, isi ukuran. Builtup: pilih profil BH atau isi H, B, tw, tf manual (tinggi web dihitung otomatis).
  2. Cek preview. Garis merah = jalur marking, biru putus-putus = gerak kosong.
  3. Salin atau unduh. Unduhan berformat .txt, ganti nama menjadi .nc/.tap bila controller membutuhkan.
  4. Set zero (G54, Builtup web pakai G55) tepat di titik zero yang dipilih, di permukaan atas plat.
  5. Builtup berhenti di M00 setelah flange: ganti plat web, set G55, lalu Cycle Start.
  6. Jalankan dulu tanpa menyentuh plat (Z tinggi) untuk cek jalur dan arah Z sebelum marking sungguhan.
